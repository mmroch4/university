## 📚 Topics

The course covers formal language theory and computability, roughly in this order:

- **Regular languages** — finite automata (DFA/NFA), regular expressions, Brzozowski derivatives, Arden's Lemma, the pumping lemma, closure properties
- **Context-free languages** — grammars, Chomsky Normal Form (CNF), pushdown automata (acceptance by final state)
- **Computability** — Turing machines, decidability, the diagonal argument, the Halting problem, and Rice's theorem

> **Note:** Lectures are numbered `1`–`20`, with `21-24.pdf` bundling the final block. Exercise sheets run `1`–`11`.
